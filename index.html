Featured Project

Spring Boot Application Deployment

End-to-end automated deployment of a Java Spring Boot application — built and packaged with Maven, quality-gated with SonarQube, stored in Nexus, containerized with Docker and rolled out on a Kubernetes cluster.

  • CI/CD pipeline orchestrated on Jenkins
  • Code quality gate on SonarQube
  • Containerized with Docker, deployed to Kubernetes
deployment.yaml

$ mvn clean package # build

$ sonar-scanner # quality gate ✓

$ nexus publish app:1.0.0

$ docker build -t app:1.0.0

$ kubectl apply -f deployment.yaml

✓ Deployment successful — Kubernetes

Featured Project

Petclinic on AWS (EKS)

Cloud-native deployment of the Java Spring Petclinic application. Infrastructure provisioned with Terraform, builds via AWS DevOps and Maven, Docker images pushed to AWS artifacts and workloads orchestrated on an Amazon EKS cluster.

  • Infrastructure as Code with Terraform
  • CI/CD with AWS DevOps & Maven
  • Deployed to Amazon EKS cluster
eks-cluster.tf

$ terraform plan # infra ✓

$ terraform apply # EKS cluster

$ aws codebuild package

$ docker push app:1.0.0

$ kubectl rollout status deploy

✓ Live on EKS cluster — AWS

Featured Project

Petclinic on Azure (AKS)

Deployed the same Java Spring Petclinic application on Microsoft Azure. Terraform provisions the infrastructure, AWS DevOps drives the pipeline, Docker images are stored in JFrog and containers run on an AKS cluster.

  • Orchestration on Azure Kubernetes Service
  • Artifacts managed in JFrog
  • Infrastructure provisioned with Terraform
aks-cluster.tf

$ terraform apply # AKS infra

$ aws codebuild package

$ jfrog upload app:1.0.0

$ docker pull & push azurecr

$ kubectl apply -f namespace.yaml

✓ Live on AKS cluster — Azure
